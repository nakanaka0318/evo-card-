# ドパバース（DOPAVERSE）

**超進化ドーパミンカードバトル** — シャドバ系ルールのデジタルカードゲームを、「ドパガキ」向けに全力でチューニングしたブラウザゲーム。

画像・音声ファイルは一切なし。カードのアート、エフェクト、効果音、BGM はすべてコードで生成しています。ビルド結果は 1 枚の HTML（約 300KB）。

## 遊び方

```bash
npm install
npm run dev        # http://localhost:5173/dev.html（開発用エントリは dev.html）
npm run build      # dist/dev.html（単一ファイル。ダブルクリックでも動く）
npm run site       # ビルドして ./index.html と ./docs/index.html を更新（GitHub Pages 用）
npm test           # ルールエンジンのテスト
npm run sim -- 10  # AI同士の自動対戦でクラス勝率を確認
npx tsx scripts/duel.ts 40 hard normal   # AIの強さ比較（同じデッキ・先後入れ替え）
npx tsx scripts/cardpower.ts 400 0       # カード強さの計測（NPCデッキ構築用 src/engine/cardpower.ts の元データ）
```

**ブラウザで遊ぶ:** https://nakanaka0318.github.io/evo-card-/

GitHub Pages は「Deploy from a branch」（`/ (root)` でも `/docs` でも可）か「GitHub Actions」のどちらでも動きます。
ゲーム本体を変更したら `npm run site` で `index.html` / `docs/index.html` を作り直してコミットしてください。

## ルール（シャドバ準拠）

- リーダー体力 20、デッキ 30 枚（同名 3 枚まで）、手札上限 9、場は 5 体まで
- PP は毎ターン +1（最大 10）。後攻は 1 ターン目に 2 ドロー
- フォロワーは出した次のターンから攻撃。《疾走》《突進》《守護》《必殺》《ドレイン》《潜伏》《バリア》《オーラ》《連撃》
- **進化**：先攻 5／後攻 4 ターン目から EP で +2/+2（出したターンでもフォロワーを殴れる）
- **超進化**：先攻 7／後攻 6 ターン目から SEP で +3/+3。自分のターン中は無敵、攻撃で倒すと相手リーダーに 1 ダメージ
- 山札が切れたら負け

## 「ドパガキ向け」の設計

虹色にするのではなく、報酬の**頻度・予測・可変性**を設計しています。

| 仕組み | 中身 |
| --- | --- |
| **DOPA ゲージ → FEVER** | カードを出す・倒す・進化・オーバーキル・**被ダメージ**で溜まる。満タンで 1 ドロー＋攻撃力 +1＋コスト -1。負けている側ほど溜まるので逆転の火種になる |
| **コンボの音階** | 1 ターンにカードを出すたび効果音のピッチが上がり、`N COMBO!` が大きくなる |
| **オーバーキル表示** | 余ったダメージを数字で見せ、ゲージにも還元 |
| **リーサル予告** | 勝ち筋が見えた瞬間に相手リーダーが赤く脈打ち、心音が鳴る |
| **ガチャ（ゲーム内）** | 運気（天井 6）と確変。SSR 確定の瞬間を「予告できる」ランダム |
| **バズ演出** | いいねを消費した瞬間、通知が画面に流れ込む |
| **レジェンド登場演出** | 57 枚すべてに専用演出（大王のレッドカーペット、ルーレの巨大ルーレット、バズリンの同接100万配信、アルゴリズム様の監視の目、シュンのストップウォッチ、レベル丸の8bit LEVEL UP、魔王の WARNING…）。対戦でのプレイ時とパック開封時に再生、タップでスキップ |
| **昇格演出** | カードパックの色が開封前に一段上がる（銀→金、金→レジェンド） |
| **リザルト** | スコア項目が 1 行ずつ加算 → ランクスタンプ → EXP バー → レベルアップ演出 → ランクアップ |
| **毎日の理由** | ログボ 7 日、デイリールーレット、デイリーミッション（1 日 1 回入れ替え可）、無料パック 1 つ |
| **離脱しにくさの逆側** | 「ドパ度」「フラッシュ軽減」「バトル速度」「AUTO」で刺激量はプレイヤーが選べる |
| **ラグ軽減** | 動作モード「サクサク／バランス／キラキラ」。初回起動時（チュートリアル前）に端末を計測しておすすめを提示、タイトル右上⚙・バトルメニュー・設定からいつでも変更可。重いのは“描画し直し”なので、box-shadow／filter／背景位置のループ演出を止め、エフェクトキャンバスの解像度と粒子数を落とす |

## モード

- **ランクマッチ**：ビギナー → ドパマスターの 8 段階。ランクに応じて AI が強くなる
- **ストーリー「ドパ道」**：6 章 16 ステージ、★3 条件つき
- **フリーバトル**：相手クラスと強さ（かんたん／ふつう／つよい／鬼）を選択
- **カードパック**：1 パック 8 枚入り（8 枚目シルバー以上確定）。1 パック／10 パック（最後のパックの 8 枚目ゴールド以上）・天井 10 パックでレジェンド確定・初回 5 パック無料・ピックアップ日替わり・プリズム（キラ）5%。開封は「パックを破る → 8 枚めくる → 次のパック」、10 パックは最後にアタリ一覧
- **デッキ構築**：コストカーブ表示、おまかせ構築、ドパ粉で生成／分解
- **ランキング**（ホーム右の📊）：最強カード／最強NPCリーダー／最強プレイヤーリーダーの3つ。カードとNPCリーダーは「あなたのバトル」（チュートリアル以外の対戦結果を自動記録。使った側の勝率を、試合数が少ないほど50%寄りに補正）と「AIシミュレーション」（`scripts/cardpower.ts`・`scripts/classpower.ts` で測ったAI同士の対戦データ）を切り替えられる。カードはクラスで絞り込み、タップで詳細。「⚔️ 相性表」タブでは全リーダー同士の勝率を表で自動作成（AI同士の総当たり／あなたの対戦記録）し、リーダー名をタップすると得意・苦手がわかる
- **カード歴史**（ホーム右の📜）：これまでのナーフ／アッパー／リワーク／調整と新カード追加を新しい順に一覧。変更前→変更後のコスト・スタッツ・テキストを並べて表示し、種類・クラス・カード名で絞り込める。履歴データは `scripts/carddump.ts` で調整前後のカードを書き出し、`scripts/patchdiff.mjs` で差分を取って `src/meta/history.ts` に追加する

## 構成

```
src/engine/   ルール本体（純データの状態 + カード定義のフック関数）、AI（ビームサーチ＋相手ターン読み＋乱数の複数サンプル）、NPCデッキはシミュレーションで測ったカード強さで構築
src/ui/       ステージ（横 1280×720 / 縦 720×1280 基準で拡縮）、バトル画面、演出、各画面
src/audio/    WebAudio の効果音とチップチューン BGM シーケンサ
src/meta/     セーブ、経済、ガチャ、ミッション、実績、ストーリー
tests/        ルールエンジンのテスト（vitest）
scripts/      AI 対戦シミュレーション、Artifact 用 HTML 変換
```

セーブはブラウザの localStorage。claude.ai の Artifact として開いた場合はアカウント側（`db` capability）にも同期します。
